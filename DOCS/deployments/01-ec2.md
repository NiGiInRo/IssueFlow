# Deployment EC2

## Proposito

Primera etapa de despliegue del MVP en AWS usando una sola maquina virtual.
Permite entender el modelo clasico antes de pasar a contenedores administrados.

## Enfoque

- una instancia EC2
- Docker y Docker Compose dentro de la VM
- gateway expuesto publicamente
- comunicacion interna entre microservicios en la misma red Docker

## Objetivo de aprendizaje

- SSH
- Security Groups
- puertos
- Linux
- despliegue manual controlado

## Alcance minimo

- levantar los cuatro servicios
- variables de entorno basicas
- persistencia minima por servicio
- validacion end-to-end del flujo principal
