# Vision And Scope

## Proposito

IssueFlow busca cumplir dos objetivos al mismo tiempo:

- practicar bases solidas de ingenieria de software
- construir un proyecto tecnico serio para portafolio
- aprender despliegue progresivo desde entorno local hasta AWS
- dejar una base que pueda evolucionar hacia una solucion real

## Vision de negocio

IssueFlow es una plataforma para registrar, asignar, atender y dar seguimiento a tickets e incidencias.
Esta pensada para equipos pequenos que hoy resuelven solicitudes por canales dispersos como WhatsApp, correo, llamadas o hojas de calculo.

## Problemas que resuelve

- falta de trazabilidad
- tickets perdidos
- desorden en la asignacion de responsables
- ausencia de historial auditable
- dificultad para medir tiempos de atencion y estados del flujo

## Roles principales

- Solicitante
- Agente
- Administrador o coordinador

## Alcance funcional V1

### Incluye

- crear ticket
- listar tickets
- consultar detalle
- asignar ticket
- cambiar estado
- registrar auditoria

### No incluye en V1

- autenticacion compleja
- dashboard avanzado
- archivos adjuntos
- SLA complejos
- observabilidad avanzada
- CI/CD completo desde el dia 1
